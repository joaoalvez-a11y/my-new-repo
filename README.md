# Dashboard de Anúncios de Veículos

Este projeto foi desenvolvido como parte da Sprint 5 do curso de Análise de Dados.

O objetivo do aplicativo é apresentar uma análise exploratória simples de um conjunto de dados de anúncios de veículos. O app permite visualizar a distribuição da quilometragem dos veículos e a relação entre preço e quilometragem por meio de gráficos interativos.

## Funcionalidades

- Visualização de histograma da quilometragem dos veículos
- Visualização de gráfico de dispersão entre preço e quilometragem
